# Install 1.1.2

[Hardmode APK / IPA downloads](https://mega.nz/folder/7TY3wZRB#PgQeCYQzxvrVGjfjX6YefA).

Android: install `NuclearThrone.Hardmode-Android-1.1.2.apk` over the existing Hardmode app. Its package identity and signing certificate are retained. Back up saves first. Shared saves require the platform's storage permission and live in `/storage/emulated/0/games/com.arkintide.nuclearthronehardmode/`; otherwise the existing private directory is used.

iOS: resign `NuclearThrone.Hardmode-iOS-1.1.2.ipa` using your own signing method. Keep the same application identity if you need to preserve the installed app's data; back it up before replacing the app. The package exposes `Documents/hardmode/` through Files sharing. It uses a compatible retained runner with fresh VM/resources, not a new native Mac build.

Hardmode settings include boss bars, throne-ball deflection, player boost and rat revival. The existing mobile mutation selector is used; no additional Grillskills module is installed.
