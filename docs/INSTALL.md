# Hardmode 1.0.12 安装

- Windows x64：完整解压 `NuclearThrone.Hardmode-Windows-1.0.12.zip`，运行 `NuclearThrone-Hardmode.exe`。保留同目录的data.win、音频、语言文件和DLL。
- Android：安装同包名及原签名的 `NuclearThrone.Hardmode-Android-1.0.12.apk`，可以覆盖本项目旧版，建议先备份存档。
- iOS：`NuclearThrone.Hardmode-iOS-1.0.12.ipa` 需要使用自己的签名方式重签安装。

安卓授权后的共享存档目录为 `/storage/emulated/0/games/com.arkintide.nuclearthronehardmode/`，不可写时回退原私有目录。iOS为应用Documents内的hardmode目录，开启文件共享。存档格式仍为GAME_BUILD3004。
