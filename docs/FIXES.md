# Hardmode 手机版1.1.4

本轮仅修改 Hardmode 移植版，基于1.1.3/build17，保持安卓包名、签名、原有存档、触屏操作和手机版自带变异界面。NTT模组版与NTTE＋NTUF未修改。

1. 取消王座苏醒时贯穿整间房的120格拆墙。保留原本战斗碰撞造成的局部破墙，墙顶和实体碰撞不再被这项额外操作拆散。
2. 头顶和屏幕顶部首领血条统一在GUI End绘制，避免被墙体、怪物或黑幕覆盖。
3. 补齐全部首领血条名称汉化，包括核能王座、王座II、通信员；Y.V保留拉丁名称。沿用现有中文字库，并检查新增字形覆盖。
4. 至高守护者使用屏幕正上方血条。
5. 至高守护者战斗分别处理GameObject及damagesource继承树，使双方弹幕、爆炸、激光及等离子冲击显示在竞技场黑幕上方，并在战后恢复深度。保留外部主动更改的深度。
6. Throne的区域入口及音乐恢复逻辑统一使用宫殿B面；从7-4进入时保持原播放句柄。
7. 保留已生效的下水道普通青蛙不转换规则；为毒蛙普通射击与死亡弹幕记录永久排除标记，避免发射者消失或伤害身份变化后又转换成辐射蛆虫。
8. 小猎人的两条延迟生成路径统一缩短等待，普通情况下在玩家出现后的8秒内完成生成，不计暂停和生成地图的时间。
9. 超级鳄鱼用局部碰撞候选替代每逻辑帧分配全部敌对弹幕列表；修正三处动画判断，避免受伤动画和声音连续重置，并缓存静止时的地面查询。
10. 毒蛙加入Loop后的下水道、废弃停车场和绿洲生成。
11. 额外首领的构造阶段与已生成实例都拦截首领入退场演出，正常首领保留原设置。
12. 王座第一阶段死亡起锁定第二阶段排警状态，同时拦截原生门创建、Rogue出口触发和已转换的待生成门。下次进入Throne时重置。
13. 箭矢撞墙时保留原生接触坐标，防止念力或后续冲量造成漂移；飞行中的箭矢保留原行为，原有消失计时保留。
14. 小猎人最后遗愿直接创建的死亡残骸在Create阶段初始化伤害身份，修复Destroy读取hitid崩溃。
15. 武器选择菜单不再直接读取不存在的GameCont；鱼叉使用已有安全区域查询。审计全部100个武器元数据回调，并通过真实武器选择器检查全部11把MOD武器。
16. 小猎人普通首领采用完整基础血量、每Loop5%及Loop1起一次30%加成，取消原生专属公式和后加项的叠乘；额外小猎人保持140基础血量，仅每Loop5%。保留联机人数及凶恶面容效果。

验证使用完全静音、独立存档、从未激活的私有桌面实际宿主VM；包括30／60帧的上述定向检查、受影响地图生成及既有关键路线回归。完整通过记录以本轮delivery-receipt.json为准。未进行安卓／iPhone真机验收或新Mac原生重建，不保证所有设备或高Loop场景恒定60帧。
