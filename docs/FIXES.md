# Hardmode 手机版 1.1.5（build 19）

本轮只修改 Hardmode 移植版；保留包名、签名、存档、触屏和手机版自带变异界面。NTTE＋NTUF及已安装的NTT模组版不在此次更改范围。

最终交付回执记录 155 个同一VM场景、142631 项断言通过。

1. 局长在Loop后增加行动和移动速度。 普通警局局长与替换局长均采用手机版每Loop增加5%行动/移动速度、最高2倍；没有将未证实的倍率描述成电脑版原始常量。
2. 金星最终首领从Loop1起的第二阶段变为Y.V。 Loop0保留原第二阶段，Loop1及以后使用Y.V。
3. 替换关底首领的局长统一从传送门出场。 替换槽位始终调用局长原生传送入场构造器。
4. Throne和HQ-5不生成额外首领。 在额外种群入口提前排除这两间房，避免消耗额外抽签或干扰正常首领。
5. IDPD单位出现前的传送门动画不要提前消失。 保留原生IDPDSpawn的动画和定时器所有权，在真正的出兵事件中应用模组权重。
6. 此前限定Loop3的敌人改为Loop1出现，警局追加规则除外。 普通区域统一使用Loop1阈值；警局的指定追加敌人继续遵守第14项。
7. 检查大量敌人、弹幕和循环后下水道的开销。 实测发现新的数值水域索引更慢，因此恢复已发布版的精确哈希批处理和干地预筛，保留房间水域状态修复；下水道使用专用绘制绑定缓存，减少每个入水实体重复分类和字符串构造，并验证相同绑定、所有权、数量及随机序列；护盾先筛局部候选再做原精确碰撞。最终回执要求专用绑定和护盾的配对宿主CPU测量不退步。保留战斗数量、伤害、掉落和顺序，不将水域查询回退描述为新的提速。
8. 玩家增强设置使用清晰中文。 多行显示玩家增强、生命上限+2、等级上限+1，沿用已有中文字库。
9. Loop2第二次终极变异增加取消选项并使用耐心图标。 取消仅消耗本局追加选择资格，不授予变异，不延迟到下关；保存/继续、联机及特殊角色仍正确处理。
10. 额外大匪和丛林大匪不触发首领演出。 构造、原生事件以及延后绑定的镜头都识别额外首领身份。
11. 额外超级水晶正常行动。 恢复包装实例的原生旋转/移动事件，并适配30Hz逻辑和60Hz宿主运动。
12. 额外诅咒超级水晶正常行动和瞬移。 恢复移动，并将侧向瞬移限制到验证过的空地位置。
13. 额外小猎人死亡后保留飞行和自爆。 创建真正的原生最后遗愿残骸，保留基础三次爆炸且不触发正常首领演出。
14. HQ的死灵法师、科技术士和IDPD freak保留Loop3门槛。 警局专属的追加种群不随普通区域前移到Loop1。
15. 替换局长也能召唤IDPD传送门。 在局长原生召唤事件调用普通动画门；入场演出阶段仍禁止攻击。
16. 局长及金星最终首领最终死亡掉落三个弹药包或医疗包。 奖励在最终死亡发放，重复死亡回调不能重发，直升机的非致命换阶段不发放。
17. 正常小猎人数量固定为1+floor(Loop/2)。 一间房只预留一次生成计划；飞行换对象、切角色和已死亡均不能重复扩增。
18. 正常多首领全部到齐才统一入场，全部死亡才统一退场。 房间账本记录待到达和存活成员；替换删除会退休旧组，额外首领排除在演出组外。
19. Throne不能误用水下状态。 生成新房和切换区域时清理过期水域缓存及玩家游泳显示状态。
20. 王座II存活时玩家只能在地板平台上行走。 以仍存在的Floor平台限制位置，第二阶段死亡后释放限制给原结尾动画。
21. 修复Player.sprite_angle未初始化崩溃。 玩家创建及结尾启用处初始化旋转字段，不依赖测试或旧存档提前赋值。
22. 减少绿洲纯显示泡泡开销。 只限制环境泡泡的屏幕可见创建预算和存活上限，保留后续随机序列以及战斗实体。
23. 王座II结尾恢复原版旋转下落。 保留完整大小和可见身体，每逻辑帧按原方式下落并旋转，不替换为传送门缩小。
24. 首领演出期间及结束后两秒玩家免伤。 只在实际演出激活保护，结束后保留60逻辑帧伤害保护，不延长控制冻结。
25. Loop1起1-3普通大匪有50%几率替换为丛林大匪。 将普通沙漠关底替换门槛前移，额外种群仍独立。
26. 金星最终首领免疫自己发射的火箭。 用不可被反射改写的原发射者标记传递到爆炸及子爆炸，普通玩家攻击仍有效；保留大鸟同样的修复。
27. 对照Y.V机枪转速和逻辑计时。 保持原始逐发角度步进与30Hz逻辑计时，验证自然发射90发的间隔和转角，不声称未经验证的桌面倍率。
28. 额外诅咒超级水晶召唤诅咒/闪电水晶。 在普通区域也根据额外首领种类选择诅咒召唤表。
29. Y.V第二阶段采用当前Loop自身血量。 不再继承被替换阶段的150血量，保留当前Loop、玩家数和凶恶面容的正常缩放。
30. 局长和金星最终首领不掉辐射，包含融化角色追加点数。 在统一辐射掉落入口排除这些首领，普通敌人仍正常掉落。
31. 替换关底首领的金星第一阶段战斗血量增加50%。 只缩放可伤害的直升机战斗预算，不缩放14250阶段切换哨兵；正常金星遭遇不受此替换加成。
32. 通信员从Loop3起使用IDPD freak特效自动复活。 使用真实原生计时和15帧复活区域特效，复活后保留武器、血条及身份。遵守第34项的新偏好。
33. 局长死亡时仅生成一次IDPD爆炸。 死亡锁防止多次回调重复生成爆炸，保留纯动画退场门和独立最终奖励。
34. 通信员自动复活间隔为Freak两倍，复活时可以有出场演出。 读取原生800逻辑帧间隔并乘二，之后播放原生15帧特效；如Freak一样可重复复活但出口开启即取消。长等待不阻挡清关，15帧复活过程阻挡清关，普通复活可入场、额外首领仍不演出。
35. 局长入场遵守桌面传送流程且不重复拳击。 先完成传送，再完成立绘/镜头，释放后才启用行动及攻击定时器。

继续保留1.1.4的王座额外120格拆墙删除、GUI End首领血条、全部首领名称汉化、至高守护者弹幕层级、宫殿B面衔接、毒蛙辐射蛆虫排除及箭矢撞墙固定等修复。

验证范围：完全静音、独立存档、未激活的私有Windows桌面宿主VM，运行30/60帧定向与路线回归；手机安装包另做资源、签名/原生兼容性和存档路径检查。主机测量不等于安卓/iPhone真机验收，也不保证高Loop恒定60帧。iOS使用兼容的既有原生Runner，需要自行重签，本轮没有新Mac原生构建。
