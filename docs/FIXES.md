# Hardmode 1.1.7 / build 21：本轮九项范围

以下记录本轮源码改动及验收结果。同一当前源码绑定 VM 的全部 56 个计划场景通过，
共 17,947 条检查，13 张实际渲染图已核验。APK、IPA 及最终交付核验通过，包含两端
包内实际代码与立绘素材、签名连续性、存档兼容性和当前冻结源码绑定。

1. **自动降帧后恢复玩家速度。** 在 Begin Step 统一切换物理回调频率和已有实体的
   速度、摩擦及原生速度缓存，避免恢复 60 帧后角色仍维持错误单位。真实移动、暂停
   恢复及首领冻结场景分别验证已有玩家和实体。

2. **已有与新生成弹幕保持一致速度。** 保留 Hardmode 脚本常量及逻辑余量，只换算
   原生物理字段。普通 Rocket 与 JockRocket 的逻辑加速冲量在原生移动调用处乘一次
   `timescale`。真实飞行测试覆盖 60→30→60、旧体和新体位移、原生最大速度及到顶时机。

3. **保留局长的原生行动与低血节奏。** 核对已保留的桌面 Last 控制事件，移除没有
   原始代码依据的重复 Alarm 推进方式。移动、射击、冲刺、传送与预警仍走原生 AI，
   通过 Loop0/1/3、30/60 帧、满血/半血的自然行为矩阵观察。

4. **低帧时首领演出按实际时间推进。** 独立演出时钟避免暂时回调不足时镜头也变成
   慢动作；暂停期间不累计演出时间。入场和退场在正常及实际注入负载下测量时长和焦点。

5. **金星最终首领转阶段仅播放二阶段入场。** 在实际阶段交接路径中登记第一阶段
   退出，抑制过渡产生的退场和重复镜头；二阶段继续使用自身的真实生成与入场流程。

6. **视频设置加入自动降帧开关，默认开启。** 持续过载时暂时使用原生 30 Hz 回调，
   随后探测恢复 60 帧。关闭后在安全的 Begin Step 恢复玩家所选帧率；真实菜单事件、
   保存 JSON 和重读均纳入检查。

7. **全部首领立绘下方名称支持中文。** 原生与自定义立绘共用中文排版，使用已注册
   中文字体并按可用区域缩放，保留 `Y.V`。两种帧率均生成实际名称对照截图供核验。

8. **局长 Loop1 起缩短技能结束后的决策等待。** 原生健康比例公式保持不变，Loop1
   起决策休息乘以 0.8。0.8 是本轮授权的平衡值，不是已验证的电脑版 Loop 公式。
   原始参考视频缺失，已有无时间标尺的联系图不能作为速度测量依据。

9. **洞窟末关无论有无 Last Wish 均只有一个尸花，并铺设丛林地板。** 保证入口和
   原生 Last Wish 后续挖掘共用同一尸花，保留可用进度并统一处理附近地板。实际生成
   工厂位于 `project/scripts/scrHMCompiled_props_mod_gml/scrHMCompiled_props_mod_gml.gml`
   的 `hm_props_mod_gml_Flower_create`，调用单例与地板帮助函数；保证入口仍由
   `native/compiled_arkintide1103.gml` 管理。普通/诅咒洞窟、有/无 Last Wish、30/60 帧
   共八种组合检查生成后及后续挖掘结果。

通过的计划包含 40 项本轮场景和 16 项定向保留回归，共 56 项，不宣称重跑历史 233 项。
最终宿主 VM 为 `306d1acf7178a506623389ca7f7b0b7cabb9726a16a4325b295dd72548fa6f82`。
60 帧演出计时场景曾发生一次无 GML 执行标记的原生启动失败，随后同 VM 两次串行
复测均通过；保留原失败记录，不据此宣称已查明或修复其启动原因。

验证使用后台静音、隔离存档的 Windows 宿主 VM，没有 Android/iPhone 真机验收，
不保证任意设备或高 Loop 恒定 60 帧。保留包名、签名与存档，iOS IPA 仍需重签。
