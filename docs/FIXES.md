# Hardmode 1.1.3 / build 17

在已发布手机版 1.1.2 / build16 上增量同步 **2026 年 11 月 3 日 17:36（UTC+08:00）起及其后**的 Hardmode 模组版改动，包括 Report17、Followup18 和 Followup19。按手机版原生对象、触屏界面和存档流程适配，不重放历史全量导入。

1. 局长与金星最终首领不替换 Throne、金星或警局关底首领。其余既有区域排除与互斥抽签规则继续保留，额外首领不成为替换目标。
2. 下水道涉水绘制与生成查询统一使用手机版实际水面、脚底支撑和干地覆盖，处理移动时水中／岸上位置反复切换。密集场景仅在一次同步遍历内建立并复用水面粗筛，保持岸边精确检测、粒子、声音、随机顺序和水波上限。
3. 密集辐射吸收使用有界的临时空间索引，稀疏、过度分散或控制器不存在时继续走原实现。不删敌人、不删辐射、不削减弹幕，不降低 AI 更新频率；不把模组版 Loop10 的桌面帧率当作手机版性能。
4. 正常大鸟 Loop0 基础血量改为150，超级鳄鱼保留120基础血量，The Messenger 基础血量改为50，王座 Loop0 血量改为1200。正常首领在既有构造及血量修改完成后应用 Loop1 起的30%加成，避免鳄鱼循环后回落、遗漏或重复加成。额外首领保留每循环5%血量规则，不加入正常首领的30%加成或循环攻击强化。
5. 修复7-4王冠密室回程：保留真正的原生王冠密室生成与进入次数；即使拾取王冠先恢复了来源区域，离开后也进入 Throne，不回到7-3或7-4。
6. 6-3出口归中央装置所有，固定在装置上方16像素，保留 IDPD 类型和原生进门流程。尸体不能抢先创建清场出口；已有出口进入传送后不再被移动。大屏幕血量改为9999。
7. Throne 恢复原始 Hardmode 的地图结构、出生点、首领位置和发电机区域，移除后来加长地图及自适应重定位。循环后警察传送门延迟到玩家出现3秒后才开始。王座醒来时，清除以整间房中线为中心、宽为房间全宽、长120格的墙体区域。
8. 王座休眠时不显示首领血条，醒来战斗后才显示。第一阶段死亡不播放通关音乐，等待王座二被击败。结尾恢复原始全尺寸旋转下落、阴影、制作名单和4000像素后的出口，防止无地板时原生死亡事件错误索引地板或抢先生成出口。
9. 血条名称统一为 **BIG BUBBLER** 和 **The Messenger**。The Messenger 使用 Rogue 的 B skin 立绘，并配套原风格名称图；其他首领标题恢复 Hardmode 原始字体风格。复活后的 Messenger 仍有血条，但不重复播放立绘、入场或退场演出，并免疫归属于自己的爆炸。
10. Loop3起宫殿普通敌人池加入王冠守护者，按小怪处理，不触发关底首领音乐。机枪手处于屏幕外或失去视线时停止攻击，攻击前使用与 Hardmode 小匪相同的感叹号预警。
11. 额外首领远离所有活着的玩家生成，保留至少160像素的安全距离；大图优先320像素以外、可用区域最远一段的位置。按实际碰撞体和占用情况检查，重试可容纳的首领类型。大老鼠沿用完整水域／建池规则，附近水塘不能把它拉回玩家身边。
12. 3-1武器箱保留手机版原生箱子、贴图、碰撞及开启事件，避免变为隐形或打不开。继续遵循螺丝刀／循环后可选能量螺丝刀规则，只改本次新掉落中最后的一把，保留大箱子的其他掉落、诅咒及弹药属性，并立即刷新武器外观。
13. 进入 Loop2 时，每局可额外选择一次尚未拥有的终极变异，保留原先终极变异及效果。使用手机版自带选择界面，保留普通变异、首次终极变异和王冠的顺序；未达条件时延后发放，继续游戏不重复领取。此项不依赖玩家增强开关。

14. 在地图生成结束时修复7-4王冠祭坛和Throne发电机周围的无碰撞墙顶：真实地板走廊移除残留墙顶，其余已有墙顶补齐紧凑静态碰撞；不为外层新增装饰或每帧扫描，也不重新封住王座醒来时清出的区域。
15. 下水道中的普通青蛙不再因毒气碰撞转化为毒气青蛙；保留游泳显示、普通AI、岸上毒气规则和自然生成毒气青蛙的行为。
16. 循环性能保留经行为对照的水面粗筛、同次遍历复用和密集辐射临时索引；按相同地图与实体规模记录实际帧耗时。新增的数值水面索引实测回退，已撤下并保留失败证据，不以微型查询测试推算手机帧率。
17. Android和iOS游戏图标使用用户提供的TDA7gy.png，等比保留完整画面及HARDMODE文字，并核对最终安装包实际选中的图标资源。

18. 局长的大球分裂改为总共10+Loop束、完整圆周等角度分布；每束仍为8发，保留原始弹速、伤害与归属，Loop0仍为10束。

19. 修复原生实体无事件切换为 Custom 实体时缺少初始化的问题：仅补齐一次性的生命周期字段，保留原实体的血量、位置、贴图及后续回调，避免 IDPD 生成门等对象尚未更新就离开关卡时读取未初始化的清理状态。清理过程保持幂等，回归检查覆盖真实转换、重复转换、Room End 与直接销毁。

20. 额外生成的普通／诅咒超级水晶不再错误触发诅咒洞净化。实体转换后同一事件中的旧对象列表可能仍包含它，现排除额外首领的关底死亡演出；正常诅咒超级水晶死亡后的洞窟和墙体恢复规则继续保留。

21. 取消进入丛林时额外赠送的一个变异点，保留正常升级、已有待选变异点、Last Wish 清除和 Loop2 终极变异。

22. 恢复金星电梯换图前的清理调用，移除上一张地图遗留的开箱贴图，保留 Y.C 休息室到最终首领的实际流程。

保留手机版简体中文、触屏操作、自带变异选择、满级前后辐射规则、玩家增强及老鼠复活设置、应用身份和存档位置。**不导入 Grillskills，也不把模组版取消汉化等桌面界面调整带入手机版。**
