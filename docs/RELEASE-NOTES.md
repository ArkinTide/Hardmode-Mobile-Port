# Hardmode 1.1.7 / build 21

1.1.7 / build 21 的 APK、IPA 及最终交付核验通过，包含两端包内实际代码与立绘素材、
签名连续性、存档兼容性及当前冻结源码绑定。同一当前源码绑定 Windows 宿主 VM 的
56 个场景通过 17,947 条检查，13 张实际渲染图已核验。

本轮调整帧率切换时玩家和既有弹幕的速度换算，修正普通火箭与 JockRocket 的加速单位，
为视频设置加入默认开启的自动降帧开关，并使首领入退场演出按实际时间推进。

金星最终首领转阶段仅保留二阶段入场；原生和自定义首领立绘名称使用中文排版。
局长保留原生行动及低血等待，Loop1 起技能结束后的决策休息乘以 0.8。这是授权平衡值，
不宣称为已验证的电脑版公式。洞窟末关无论有无 Last Wish 均只有一个尸花并铺设丛林地板。

通过的计划为 40 项本轮场景和 16 项定向保留回归；不宣称重跑历史 233 项。
60 帧演出计时曾出现一次原生启动失败，之后同 VM 两次串行复测均通过，
原失败记录保留，启动原因未查明。局长原始参考视频缺失，不能据此测定电脑版公式。

保留包名、签名身份和存档路径。测试使用后台静音、隔离存档的 Windows 宿主 VM，
未进行 Android/iPhone 真机验收，不保证任意设备或高 Loop 恒定 60 帧。IPA 需重签。

APK、IPA 及 SHA256 校验清单通过既有 Hardmode 专用 MEGA 目录分发；GitHub 发行内容
为文本源码、工程元数据和说明。下载后请对照本版本校验清单检查文件。
