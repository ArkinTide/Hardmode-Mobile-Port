# Hardmode Mobile Port 1.1.7

Hardmode b24 手机移植版，build 21。本轮处理九项请求，详见
[修复记录](docs/FIXES.md)和[安装说明](docs/INSTALL.md)。

1.1.7 / build 21 的 APK、IPA 和最终交付核验通过，包含包内实际代码、立绘与名称素材、
签名连续性及存档兼容性。全部 56 个计划场景在同一当前源码绑定 Windows 宿主 VM 上
通过，共 17,947 条检查，13 张实际渲染图已核验。60 帧演出计时场景在一次原生启动
失败后，两次串行复测均通过；原失败记录保留。

帧率切换在游戏处理移动前统一换算已有实体的物理速度和缓存，同时修正普通火箭及
JockRocket 的加速单位。视频设置加入默认开启的自动降帧开关；首领演出按实际时间推进。
洞窟末关无论有无 Last Wish 均保留一个尸花并铺设丛林地板。局长 Loop1 起技能结束后
决策等待乘以 0.8；这是本轮授权的平衡值，不宣称为已证实的电脑版公式。

保留原包名、签名身份、存档路径和手机版变异选择界面。GitHub 发行内容为文本源码及
工程元数据，APK、IPA 和 SHA256 校验清单通过既有 Hardmode 专用 MEGA 目录分发。
下载后请对照本版本校验清单检查文件。电脑版模组与 NTTE/NTUF 另行维护。

测试使用后台静音、隔离存档的 Windows 宿主 VM。尚未进行 Android/iPhone 真机验收，
不保证任意设备或高 Loop 恒定 60 帧。iOS 使用兼容的既有原生 Runner 和新游戏资源，
IPA 需要重签。构建与验收流程见 [BUILDING](BUILDING.md)。
